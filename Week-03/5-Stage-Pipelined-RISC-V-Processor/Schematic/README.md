# Processor Schematics

## Overview

This folder contains the RTL schematics of the **5-Stage Pipelined RISC-V Processor**, generated using **Xilinx Vivado**.

Due to the size and complexity of the complete processor design, the schematic has been divided into two parts for better visibility and easier analysis. A complete schematic is also included to provide an overall view of the processor architecture and module connectivity.

## Included Schematics

### 1. Full Processor Schematic

The complete RTL schematic provides an overall view of the **5-Stage Pipelined RISC-V Processor** and shows the connectivity between the major modules of the design.

### 2. Schematic — Part 1

This image shows the first section of the processor schematic in greater detail for improved visibility of the internal modules and signal connections.

### 3. Schematic — Part 2

This image shows the remaining section of the processor schematic in greater detail, completing the overall processor architecture.
