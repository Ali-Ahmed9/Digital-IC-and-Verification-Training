# Single-Cycle RISC-V Processor

## Overview

This project focuses on the design and implementation of a **Single-Cycle RISC-V Processor using Verilog HDL**.

The processor was developed from scratch by first analyzing the RISC-V architecture 
and then implementing and integrating its individual hardware components into a complete processor.

The design was simulated and verified using **Xilinx Vivado** to observe processor behavior
and verify the execution of supported RISC-V instructions.



##  Processor Development Flow

The processor was developed progressively:


RISC-V Architecture Analysis
            ↓
Individual Hardware Components
            ↓
Component Verification
            ↓
Top-Level Processor Integration
            ↓
Testbench Development
            ↓
RTL Simulation
            ↓
Instruction Verification
