# Week 10 — Labs
======================================================

This folder contains practical exercises focused on UART synthesis, SRAM memory replacement, and PLL integration using Verilog HDL and Cadence tools.

======================================================

## Lab 04 — UART Synthesis and Debug

- UART RTL synthesis
- Serial communication verification, 
- Synthesis script preparation,
- SDC clock constraints,
- Netlist generation,
- Gate-level simulation using Cadence Genus and Incisive.

======================================================

## Lab 05 — Memory Replacement

Study and implementation of memory replacement using Single-Port and Double-Port SRAM structures.

======================================================

## Lab 06 — PLL Instantiation in a Verilog Design

Implementation of a 16-bit counter using a behavioral clock divider and an SMIC40 PLL hard macro,
Including PLL configuration,
Simulation, synthesis,
Gate-level verification.

======================================================
