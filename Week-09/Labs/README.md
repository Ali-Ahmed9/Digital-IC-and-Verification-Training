# Week 09 — Labs

This folder contains practical exercises focused on sequential RTL synthesis and transistor-level CMOS design using Cadence tools.

======================================================

## Lab 03 — Sequential Design Synthesis
- Sequential logic implementation using Verilog HDL
- Synthesis script preparation using `synthesis_script.tcl`
- Timing constraint generation using `constraint.sdc`
- RTL synthesis using Cadence Genus
- Synthesized netlist generation
- Netlist simulation using Cadence Incisive

[Lab no 3 sol.pdf](https://github.com/user-attachments/files/35172493/Lab.no.3.sol.pdf)

======================================================

## Lab 03B — Inverter Schematic and Layout on Virtuoso
- CMOS inverter schematic creation using gpdk045
- Transistor-level circuit implementation
- Transistor sizing
- Transient analysis and simulation
- Symbol creation
- Schematic and layout design using Cadence Virtuoso
