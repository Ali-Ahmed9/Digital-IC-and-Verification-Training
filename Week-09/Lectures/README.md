# Week 09 — Lectures

======================================================

This folder contains lecture materials covering **Static Timing Analysis (STA), timing models, and timing constraints for synchronous digital designs**.

## Lecture Topics

======================================================

### 1. Timing Models and STA
- Timing arcs and delay calculations
- Rise/fall transition times and output slew
- Timing tables and cell characterization
- Operating conditions and process variables
- Combinational and sequential timing models

======================================================

### 2. Setup and Hold Analysis
- Setup and hold timing checks
- Timing parameters and timing table interpretation
- Launch and capture flip-flops
- Slack calculation and required-time estimation

======================================================

### 3. Constraints for Synchronous Designs
- STA environment and case studies
- Input and output path constraints
- Data stability requirements
- External attributes and virtual clocks
- Driving cells, input transitions, and output loads
- Design Rule Checks

======================================================

### 4. Timing Constraint Commands
- `set_driving_cell`
- `set_input_transition`
- `set_load`
- `set_min_library`
- `set_operating_conditions`
- `set_wire_load_model`
- `set_wire_load_mode`
- `set_drive`

======================================================
