# Week 02 — SystemVerilog & Advanced Computer Architecture

## Overview

Week 02 focused on strengthening the fundamentals of **SystemVerilog RTL design** and introducing key concepts of **Advanced Computer Architecture and RISC-V**.

The week was divided into two portions:

==========================================================
###  Portion 01 — SystemVerilog Fundamentals

Covered the foundations of SystemVerilog, including:

- SystemVerilog syntax and module structure
- Nets, variables, and data types
- Structural and dataflow modeling
- Continuous assignments and operators
- Testbench and simulation concepts
- Parameterised modules and generics
- Packages, and generate constructs
- Procedural blocks and event control
- Blocking vs non-blocking assignments

==========================================================

### 🖥️ Portion 02 — Advanced Computer Architecture

Covered the fundamentals of computer architecture and RISC-V, including:

- Computer architecture and processor performance
- Performance improvement and parallelism
- Instruction Set Architecture (ISA)
- RISC-V ISA and RV32I
- RISC-V instruction formats and types
- Assembly and binary representation
- Processor datapath
- Program Counter, Register File, ALU and Memory
- Control Unit and Multiplexers
- Load, Store, Branch and Jump operations
- Single-cycle and Multi-cycle processors
- IF, ID, EX, MEM and WB execution stages

==========================================================

##  Tools & Technologies

- SystemVerilog
- Verilog HDL
- RISC-V
- Xilinx Vivado
- RTL Simulation
