# Week 06 — Embedded C, DMA, Driver Development & PCB Design

Week 06 of the **Digital IC Design & Verification Training** focused on strengthening practical knowledge of **C and Embedded C, DMA architecture, hardware driver development, build processes, and PCB design**.

The week combined both **theoretical lectures and hands-on laboratory activities**, covering the complete flow from embedded software fundamentals and register-level programming to hardware interfacing and PCB implementation.

==============================================================

##  Lectures

The lecture portion of Week 06 covered the following major areas:

## 1. C & Embedded C Fundamentals

The lecture introduced the fundamentals of C programming from an embedded systems perspective.

Topics included:

- Why Embedded Systems are different
- Microcontroller vs. Microprocessor
- Inside the Microcontroller
- GCC, MinGW-w64 & Visual Studio Code
- C and Embedded C fundamentals
- Important data types
- Bitwise and shift operators
- Pointers and memory addresses
- Embedded C keywords
- Bare-Metal Programming
- Embedded software development concepts

==============================================================

## 2. DMA Architecture

The DMA Architecture lecture introduced **Direct Memory Access (DMA)** and its role in embedded systems.

The lecture focused on the concept of transferring data between memory and peripherals with reduced CPU involvement and understanding the basic architecture and operation of DMA.

==============================================================

## 3. Driver Development

The Driver Development lecture focused on understanding how software communicates with hardware through drivers.

Topics included:

- What is a driver?
- Role and responsibilities of a driver
- Relationship between hardware, drivers, and application code
- C tools used in driver development
- `#define`
- `typedef`
- `struct`
- `volatile`
- Pointers
- Bitwise operators
- Reading hardware datasheets
- Converting register tables into C definitions
- Building hardware drivers
- GPIO driver development
- PWM driver development
- Header and source file organization
- Identifying and fixing driver implementation issues

==============================================================

## 🧪 Labs & Practical Work

The practical portion of Week 06 included assignments, software simulations, and hardware design activities.

==============================================================

## 1. Assignment & Lab Quiz

**Topic:** Build Process, Toolchain, Porting, Linker Script & Driver Development

The assessment included:

- 10 quiz questions
- 10 assignment tasks
- Fully auto-graded evaluation
- Name and roll number submission
- Offline execution
- Automatic score generation
- Submission code for score recording

The assessment provided practical revision of the build process, toolchain concepts, porting, linker scripts, and driver development.

==============================================================

## 2. C & Embedded C Lab Report

Different **C and Embedded C laboratory exercises** were simulated using **Visual Studio Code**.

The practical work focused on applying C and Embedded C concepts through programming and simulation.

==============================================================

## 3. Circuit Design & PCB Layout in Altium Designer

A complete regulator circuit was designed in **Altium Designer**, covering the process from schematic design to PCB layout and manufacturing outputs.

## Objective:

Design a regulator PCB capable of converting:

## 5V → 3.3V

## Selected Component:

## LM3940 — Linear LDO Regulator

- Output: 3.3V
- Current capability: Up to 1A
- Package options: SOT-223 / TO-220

The practical workflow included:

- Schematic design
- Component symbol
- Footprint assignment
- PCB layout
- Routing
- Design verification
- Manufacturing outputs
