# Week 01 – Lab 03

# Dataflow Modeling Using Verilog HDL

---

## 📖 Overview

This lab introduces **Dataflow Modeling** in Verilog HDL using continuous assignment (`assign`) statements. 
The focus is on designing combinational circuits using Boolean expressions, understanding propagation delays,
and analyzing simulation behavior.

---

# 🎯 Objectives

- Understand continuous assignment (`assign`) statements.
- Learn implicit continuous assignment.
- Study propagation delays in dataflow modeling.
- Design combinational circuits using Boolean expressions.
- Simulate digital circuits using Dataflow Modeling.

---

# 📝 Lab Tasks

## Task 1 – 2×4 Decoder

Designed a **2×4 Decoder** using only **Dataflow Modeling**.

### Analysis

- Case (a): Different propagation delays
- Case (b): Equal propagation delays
- Case (c): Ideal circuit (No propagation delay)

Simulation results were analyzed for each case.

---

## Task 2 – 8×1 Multiplexer

Designed an **8×1 Multiplexer** using only **assign statements**.

Included:

- Circuit Diagram
- Truth Table
- Simulation Results

---

## Task 3 – 4-bit Subtractor

Designed and simulated a **4-bit Subtractor**.

Included:

- High-Level Block Diagram
- Simulation Results

---

## Task 4 – BCD Divisible by 4 Detector

Designed a combinational circuit that detects whether a **4-bit BCD input** is divisible by 4.

Simulation includes all possible input combinations.
