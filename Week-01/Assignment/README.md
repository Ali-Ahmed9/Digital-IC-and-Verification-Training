# Week 01 – Assignment 01

# Cola Vending Machine FSM using Verilog HDL

---

## 📖 Overview

This assignment implements a **Cola Vending Machine** using a **Finite State Machine (FSM)** in Verilog HDL. 
The machine accepts coins of Rs. 5 and Rs. 10 and dispenses one can of cola when a total of Rs. 15 has been inserted.

The design demonstrates practical application of FSM concepts including state transitions, 
input handling, output generation, and automatic reset.

---

# 🎯 Objectives

- Design an FSM-based vending machine.
- Apply state transition logic.
- Accept multiple coin denominations.
- Generate output upon reaching the required amount.
- Automatically reset after dispensing.

---

# 📌 Specifications

- Cola Price = Rs. 15
- Accepted Coins:
  - Rs. 5
  - Rs. 10
- No Change Returned
- Automatic Reset after Dispensing
- FSM-based Verilog Implementation

---



# 🛠️ Tools Used

- Verilog HDL
- Vivado Design Suite
