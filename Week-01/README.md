# Week 01

## Overview

This week focused on the fundamentals of Digital IC Design using Verilog HDL. The labs introduced gate-level modeling, hierarchical design, module instantiation, and simulation of basic digital circuits.

## Learning Objectives

- Understand Gate-Level Modeling
- Learn Hierarchical Design
- Design combinational circuits using Verilog
- Write Testbenches
- Perform Functional Simulation
