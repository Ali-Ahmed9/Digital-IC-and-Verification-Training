# Week 01 – Lab 02

# Hierarchical Gate-Level Modeling Using Verilog HDL

## 📖 Overview

This lab extends the concepts of Gate-Level Modeling by introducing **Hierarchical Design** in Verilog HDL.
The focus is on designing complex digital circuits by reusing smaller modules through module instantiation, 
promoting modularity and code reusability.

---

## 🎯 Objectives

- Extend Gate-Level Verilog programming skills.
- Understand hierarchical design methodology.
- Learn module instantiation.
- Construct complex digital circuits using reusable modules.
- Perform functional simulation using Verilog HDL.

---

# 📝 Lab Tasks

## Task 1 – Half Adder & Full Adder

### Half Adder

- Implemented using Gate-Level Modeling.
- Verified truth table using Vivado Simulator.

### Full Adder

- Constructed using two Half Adder modules.
- Applied hierarchical modeling.
- Verified all possible input combinations.

---

## Task 2 – Multiplexer

### 2×1 Multiplexer

- Designed using primitive gates.
- Verified truth table.

### 4×1 Multiplexer

- Implemented using multiple 2×1 Multiplexer modules.
- Demonstrated module hierarchy and reuse.

---

## Task 3 – Decoder

Designed a **3×8 Decoder with Enable** using:

- 1×2 Decoder
- 2×4 Decoder

Implemented using hierarchical module instantiation.

---

## Task 4 – 16-bit Ripple Carry Adder

Designed a **16-bit Ripple Carry Adder** using sixteen Full Adder modules.

Features:

- 16-bit Inputs (A, B)
- Carry-In (Cin)
- 16-bit Sum Output
- Carry-Out (Cout)
